## Коротко о результатах

- **Ядро 2026-07-28 в TS SDK 2.4.0 работает.** 13 зондов: `server/discover`, валидация
  `Mcp-Method`/`Mcp-Name` (`-32020`), неподдерживаемая версия (`-32022`), legacy-fallback
  2025-11-25, `tasks/get` на сервере без Tasks (`404 / -32601`).
- **Серверный рантайм Tasks есть только в C# и Rust** (`ModelContextProtocol.Extensions.Tasks`
  2.4.0 и `rmcp` 3.11.0). C# проверен живьём: 12 из 12 вызовов создали задачу, поллинг завершил
  её за ~2,1 с. Rust-примеры `rmcp` запущены: `slow_sum` вернул `CreateTaskResult`, поллинг дал
  `Completed` с результатом `42`. В TypeScript 2.4.0 и Python 2.3.0 рантайма нет; Java 2.2.0 и
  Go 1.8.0 — без Tasks, обе проверены живыми клиентом и сервером.
- **Long-poll внутри `get_status` сокращает число ходов** с 63 до 8 на 180-секундной задаче
  (7,9×), а объём tool-результатов — примерно в 57 раз (оценка O(N²)).
- **Внешнее хранилище без heartbeat опасно:** после рестарта задача навсегда остаётся `working`.
  Recovery без идемпотентности выполнил побочный эффект дважды — воспроизведено.

Подробности и оговорки — в `experiments/RESULTS.md`; в статье отдельно помечено, что измерено,
а что взято из вторичных источников.

## Быстрый старт

```powershell
cd experiments
npm install
node exp0_probe\probe.mjs
node expA_polling\run.mjs
node expB_crash\run.mjs
```

Всё сразу, включая Go, C#, Rust и Java:

```powershell
powershell -ExecutionPolicy Bypass -File experiments\run-all.ps1
```

Требуется Node.js 24.x (прогоны сделаны на 24.20.0). Полные инструкции, переменные окружения и
описание файлов результатов — в `experiments/README.md`.

## Ограничения

Клиенты (Claude Code, ChatGPT, Cursor, claude.ai, Claude Desktop, VS Code) не тестировались: данные
о них — из публикаций Upstash/Upsy и трекеров. «Модель» в эксперименте A — детерминированный
цикл вызовов, а не LLM. Go, C#, Rust и Java прогнаны живьём; Java — только modern-ядро, потому что
расширения Tasks в 2.2.0 нет.
